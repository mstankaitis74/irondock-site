# irondock-site

Irondock website, served by GitHub Pages at https://irondock.dev.

- `index.html` – home page: the whole dock, one berth per app
- `dock.css`, `dock.js` – shared styles and parallax for the harbour scene (used by every page except the privacy policy)
- `beatsy/index.html` – Beatsy app page (Berth 01); copy it for the next app and change the berth number, texts and `--berth` colour
- `beatsy/privacy/index.html` – Beatsy privacy policy (copy of `C:\programming\beatsy\application\androidApp\src\main\assets\privacy-policy.html`; update both together)
- `CNAME` – custom domain for GitHub Pages
- `app-ads.txt` – add here once the AdMob account exists
